# Monthly Mission Point Calculator

月間ミッションポイントの達成に必要なライブ回数を計算するための簡易Webツールです。

## 概要

現在のミッションポイント、ライブボーナス消費量、カラフルパスの有無、CM視聴やみんなでライブの実施予定などを入力すると、月末までに必要なライブ回数とライブボーナス不足分の目安を計算します。

ブラウザ上で完結する静的HTMLツールなので、Pythonやサーバー環境は不要です。

## 主な機能

- 現在のミッションポイントから月間目標までの残りポイントを計算
- CM視聴の有無を考慮
- チャレンジライブの実施有無を考慮
- みんなでライブ3回分の追加獲得を考慮
- カラフルパス所持によるポイント増加を考慮
- イベントボーナスミッションで獲得予定のポイントを任意で考慮
- 優先枠と不足分の追加対応を分けた日別予定を表示
- 不足分の追加対応では、ライブボーナス消費量を固定値として使い、チェック時のみ上限として調整可能
- 現時刻から月末までのライブボーナス自然回復数を計算
- 入力変更時に結果を自動更新
- 入力値が範囲外の場合に注意表示

## 使い方

公開ページを開き、必要な項目を入力してください。入力が有効な場合、結果は自動で更新されます。
ページを開いたまま時間が経った場合は、「現在時刻で更新」ボタンで自然回復数を再計算できます。

GitHub Pagesで公開している場合、URLは以下の形式になります。

```text
https://<ユーザー名>.github.io/<リポジトリ名>/
```

ローカルで確認する場合は、`index.html` をブラウザで開いてください。

## 入力項目

- 現在のミッションポイント
- 1回のライブボーナス消費量
- ライブボーナス消費量を上限として調整するか
- カラフルパスの有無
- CMを見るか
- チャレンジライブを行うか
- みんなでライブを3回行うか
- イベントボーナスミッションを考慮するか
- イベントボーナスミッションで獲得予定のポイント
- 今日の固定分をすでに消化したか

## 注意点

このツールは目安計算用です。ゲーム内の仕様変更、イベント内容、ボーナスミッションの報酬量変更などには自動対応しません。

ライブボーナスの自然回復は、現時刻から月末まで30分ごとに1回復するものとして計算します。ただし、実際にはライブボーナスが上限に達している間は自然回復が止まるため、プレイ状況によって結果が変わる可能性があります。

## 開発・更新方法

このリポジトリをローカルにcloneして、`index.html` を編集します。

```bash
git clone https://github.com/harumiitsu1004/monthly-Mission-point-calculator.git
cd monthly-Mission-point-calculator
```

変更後は以下の流れでGitHubに反映します。

```bash
git status
git add index.html README.md
git commit -m "Update calculator"
git push
```

GitHub Pagesを使用している場合、push後しばらくすると公開ページにも反映されます。
